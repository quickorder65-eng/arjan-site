Политика обработки персональных данных

Действует для сайта arjan.kz. Описывает, какие данные собираются через формы сайта и как они используются.

1. Общие положения

Отправляя заявку через формы на сайте arjan.kz (заказ расчёта, заявка застройщика, заказ каталога), пользователь передаёт компании ArJan персональные данные: имя, номер телефона и, при необходимости, дополнительную информацию о запросе (город, тип продукции, комментарий).

2. Цели обработки данных

  • Связь с пользователем для расчёта стоимости продукции;
  • Подготовка коммерческого предложения по заявке застройщика;
  • Отправка каталога продукции;
  • Консультация по вопросам о продукции и услугах ArJan.

3. Хранение и передача данных

Полученные через формы данные используются менеджерами ArJan исключительно для обработки заявки и не передаются третьим лицам, за исключением случаев, предусмотренных законодательством Республики Казахстан.

4. Согласие пользователя

Отправляя форму на сайте, пользователь подтверждает согласие на обработку указанных персональных данных в целях, перечисленных в разделе 2.

5. Контакты по вопросам обработки данных

По вопросам, связанным с обработкой персональных данных, можно обратиться по телефону 8 (708) 800-59-29 или через WhatsApp.
