# ArJan — сайт

Многостраничный сайт компании ArJan (Алматы): поставка алюминиевого и пластикового
профиля, изготовление окон, дверей и раздвижных конструкций, замер, доставка и монтаж.
Vanilla HTML/CSS/JS, без сборки и без зависимостей — открывается напрямую или через
любой статический хостинг.

## Как запустить локально
Открыть `index.html` напрямую в браузере, либо поднять локальный статический сервер
(рекомендуется, чтобы корректно работали абсолютные пути `/assets/...`, `/public/...`):
```
npx serve .
# или
python -m http.server 8000
```

## Структура
```
arjan-site/
├── index.html              ← главная страница
├── portfolio.html           ← /portfolio — объекты с продукцией ArJan (фильтры + лайтбокс)
├── production.html          ← страница «Производство»
├── developers.html          ← страница «Застройщикам»
├── privacy.html             ← политика обработки персональных данных
├── 404.html                 ← страница «не найдено»
├── sitemap.xml / robots.txt
├── products/                ← 9 страниц товарных категорий
├── assets/
│   ├── css/style.css        ← общие стили всех страниц
│   └── js/
│       ├── site-data.js     ← данные филиалов, товарных категорий и видео (единый источник)
│       ├── main.js          ← общая логика: меню, WhatsApp, филиалы+карта, FAQ, формы, карусель
│       ├── calc.js           ← калькулятор стоимости (главная)
│       └── portfolio.js      ← фильтры и лайтбокс портфолио
└── public/
    ├── first screen/         ← исходные фото профиля для первого экрана (не изменять)
    ├── products/hero/        ← оптимизированные копии для первого экрана
    ├── photos/                ← исходные фотографии (не удалять)
    ├── portfolio/             ← обработанные фото объектов (full/thumb, jpg/webp)
    ├── production/            ← кадры производства из видео (full/thumb, jpg/webp)
    ├── videos/                ← исходные видео (не изменены) + /web (сжатые версии) + /posters
    └── branding/               ← favicon, apple-touch-icon, og-изображение
```

## Как изменить данные филиалов или товаров
Все адреса, телефоны, график филиалов и описания товарных категорий вынесены в
`assets/js/site-data.js` — правки там применяются на всех страницах автоматически
(карточки филиалов, карта, WhatsApp-виджет, футер).
